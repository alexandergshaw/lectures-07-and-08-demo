# Alex Shaw — Portfolio

A responsive, three-page portfolio built with semantic HTML, CSS Grid, and Flexbox. The pages share one stylesheet and a Google Fonts pairing, and adapt for mobile, tablet, and desktop screens.

## Pages

- `index.html` — introduction and selected work
- `projects.html` — project details
- `about.html` — background and skills

## Run locally

Open `index.html` in a browser, or serve the repository root with any static web server. No build step or dependencies are required.

## Deploy to GitHub Pages

1. Push the repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing these files and the `/ (root)` folder, then save.
5. Use the published Pages URL to open the site. The shared navigation links connect all three pages.
